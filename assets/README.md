# Assets

Place these files here before building:

- `icon.png` — 1024x1024 app icon
- `splash.png` — 1284x2778 splash screen (portrait)
- `adaptive-icon.png` — 1024x1024 Android adaptive icon foreground
- `favicon.png` — 32x32 web favicon
- `notification-icon.png` — 96x96 Android notification icon (white on transparent)

Brand colors for assets:
- Background: #1E4D9B (Eagle Pathway Blue)
- Icon: White eagle/pathway logo on blue background
